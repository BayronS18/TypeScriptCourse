# TypeScript Essentials & Advanced Typing Course

Repositorio con ejercicios y proyectos enfocados en la adopción de TypeScript para el desarrollo de aplicaciones robustas.

## Conceptos y Tecnologías Aplicadas
- **Tipado Estático Basico y Avanzado:** Primitive types, `union types`, `intersection types` y `type aliasing`.
- **Interfaces y Contratos:** Definición de estructuras de datos, extensión de interfaces e integración con objetos.
- **Genéricos (Generics):** Creación de funciones, interfaces y clases reusables y fuertemente tipadas.
- **Clases y POO con TS:** Modificadores de acceso (`public`, `private`, `protected`) e implementación de interfaces.
- **Integración y Configuración:** Uso del compilador (`tsc`), archivo `tsconfig.json` y buenas prácticas de tipado sin recurrir a `any`.
